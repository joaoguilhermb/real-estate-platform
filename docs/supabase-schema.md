Supabase Schema
Table: `imoveis`
Main table storing all property listings.
```sql
create table imoveis (
  imoveis_id    bigint generated by default as identity primary key,
  created_at    timestamp with time zone default now(),
  corretor_id   text,
  titulo        text,
  "descrição"   text,
  tipo          text,
  finalidade    text,
  "Valor"       numeric,
  areaConstr    float,
  areaTot       float,
  quartos       integer,
  banheiros     integer,
  garagem       integer,
  "Cidade"      text,
  bairro        text,
  imagem        text,
  "localização" text,
  disponivel    boolean default true
);
```
Column Reference

Column	Type	Notes

`imoveis_id`	bigint	Auto-generated primary key
  
`created_at`	timestamptz	Auto-set on insert

`corretor_id`	text	FK reference to agent

`titulo`	text	Property listing title

`descrição`	text	Full description

`tipo`	text	`casa`, `apartamento`, `lote`, `cobertura`, etc.

`finalidade`	text	`venda` or `aluguel`

`Valor`	numeric	Listing price in BRL

`areaConstr`	float	Built area in m²

`areaTot`	float	Total land area in m²

`quartos`	integer	Number of bedrooms

`banheiros`	integer	Number of bathrooms

`garagem`	integer	Number of garage spots

`Cidade`	text	City name

`bairro`	text	Neighborhood

`imagem`	text	Public URL to property image

`localização`	text	Address or map coordinates

`disponivel`	boolean	`true` = available, `false` = sold/rented

---
RLS (Row Level Security)
For the listing page to work without user authentication, the `imoveis` table needs a public read policy:
```sql
-- Allow anyone to read available properties
create policy "allow public read"
on imoveis
for select
to anon
using (true);
```
> Without this policy, all Supabase queries from FlutterFlow return empty results, causing the ListView to load indefinitely.
---
Filtering Notes

Case sensitivity

Supabase's `LIKE` operator is case-sensitive by default. Use `ILIKE` for case-insensitive matching (e.g. "Casa" matches "casa").

Numeric vs String types

FlutterFlow Dropdowns return `String` values. When filtering numeric columns (`quartos`, `banheiros`, `Valor`), type conversion is required. This is handled via Custom Functions (`stringToInt`, `stringToDouble`).
Column naming

Some columns use capitalized names (`Valor`, `Cidade`) as created in the Supabase dashboard. Make sure the exact column name (including case) matches what is used in FlutterFlow's query builder.
